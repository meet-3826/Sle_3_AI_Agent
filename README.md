# # SLE-3: C4 Model

## Project
8-Puzzle Solver using BFS and A*

## Description
This SLE represents the architecture of an 8-Puzzle Solver using the C4 Model.

The four levels used are:
- Context Diagram
- Container Diagram
- Component Diagram
- Code Level

BFS explores states level by level, while A* uses Manhattan Distance for efficient searching.

## Tools Used
Python, draw.io, GitHub, ChatGPT
